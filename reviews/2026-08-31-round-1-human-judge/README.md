# Adversarial round 1 — human and judge ergonomics

This round attacked the cold installed-wheel experience, the first real project workflow, readiness recovery, copy/paste safety, and the fastest path for a judge to observe the central failure mode. Findings were derived from executable probes, not accepted from narrative claims.

The round added no-clobber onboarding, actionable readiness output, a credential-free paired judge demonstration, a shared exclusive publication primitive, runtime-derived onboarding schema, and regression coverage. Closure also caught and repaired a repository side effect in the first demo implementation and a brittle schema-count assertion.

`findings.json` accounts for every confirmed issue. `qualification.json` binds the final source and executable validation. `quickstart-receipt.json` is the actual paired demonstration receipt; its report paths are ephemeral and the receipt is evidence of this run rather than a portable release locator.
